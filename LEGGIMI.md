# Ramo «dati» di TPL Venezia

File generati in automatico dal workflow `.github/workflows/dati.yml` (non modificarli a mano).
I telefoni li scaricano dal CDN (jsDelivr) per non pesare sul server; il server ne controlla l'impronta (vedi `fissi.js` sul ramo main).

- `fissi/` fermate, linee e tracciati derivati dai GTFS statici ACTV (open data).
- `pedoni/` rete pedonale in mattonelle derivata da OpenStreetMap: © OpenStreetMap contributors, disponibile con licenza
  Open Database License (ODbL) 1.0, https://www.openstreetmap.org/copyright — i dati derivati restano sotto la stessa licenza.
